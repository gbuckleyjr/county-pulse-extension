Dashboard Extension Plan
Research date: 2026-05-12

Working title
- Where America Moved in the 2010s

Implementation status
- County Pulse extension scaffold built at 2026.05.11\migration-pulse-extension.
- Hosted preview URL: https://gbuckleyjr.github.io/county-pulse-extension/migration-pulse-extension/index.html
- Tableau manifest: 2026.05.11\migration-pulse-extension\MigrationPulse.trex
- Browser preview uses the hosted CSV fallback when outside Tableau.

Core story
- Show which U.S. counties gained or lost people through net migration during the 2010s.
- Let the audience compare raw migration volume with migration rate so large counties do not dominate every interpretation.
- Use sex split as a secondary story: where male and female net migration moved together, and where one side diverged.

Recommended extension direction
- Build a dashboard extension first, not a viz extension.
- Reason: a dashboard extension can sit inside the Tableau dashboard, read a prepared worksheet as a data feed, and render a custom animated canvas/SVG view with fewer Marks-card constraints.
- Later upgrade path: convert the animation into a worksheet/viz extension if the goal becomes a reusable custom chart type that appears on the Tableau Marks card.

Extension concept
- Extension name: County Pulse
- Workbook view title: Migration Pulse
- Type: Tableau dashboard extension loaded through a .trex manifest.
- Visual: animated U.S. county map where each county pulses outward or inward based on net migration.
- Encoding:
  - Blue/green = net gain.
  - Red/orange = net loss.
  - Pulse size = absolute Total Net Migrants.
  - Fill intensity = Net Migration Rate per 100.
- Important truth-in-data rule: do not animate county-to-county paths. This dataset contains net balances, not origins and destinations.

Dashboard layout
- Top band: title, one-sentence takeaway, source/method footnote.
- Main left/center: Migration Pulse extension as the hero visual.
- Right panel: top gain counties, top loss counties, selected county details.
- Bottom panel: native Tableau supporting sheets:
  - Diverging bar chart for top gains and losses.
  - Bubble/scatter: Total Net Migrants vs Net Migration Rate per 100, sized by 2020 population.
  - Female vs male net migration scatter or dumbbell.
- Filters:
  - State.
  - Migration direction: gain, loss, flat.
  - Population size band.
  - Show by raw count or rate.
  - Top N counties.

Tableau data prep
- Add calculated fields:
  - Total Population 2020 = [Female Population 2020] + [Male Population 2020]
  - Total Net Migrants = [Net Female Migrants] + [Net Male Migrants]
  - Net Migration Rate per 100 = [Total Net Migrants] / [Total Population 2020] * 100
  - Absolute Net Migrants = ABS([Total Net Migrants])
  - Migration Direction = IF [Total Net Migrants] > 0 THEN "Gain" ELSEIF [Total Net Migrants] < 0 THEN "Loss" ELSE "Flat" END
  - Gender Gap = [Net Female Migrants] - [Net Male Migrants]
- Exclude State Total rows from county-level visuals.
- Keep State Total rows for optional state summary sheet.

Extension data feed worksheet
- Create hidden worksheet named Extension Feed.
- Include one mark per county.
- Required fields:
  - State
  - State FIPS
  - County
  - County FIPS
  - Total Population 2020
  - Total Net Migrants
  - Net Migration Rate per 100
  - Net Female Migrants
  - Net Male Migrants
  - Gender Gap
- Apply the same dashboard filters to this worksheet so the extension reacts with the dashboard.

Extension architecture
- Folder: 2026.05.11/migration-pulse-extension
- Files:
  - MigrationPulse.trex
  - index.html
  - src/migration-pulse.js
  - src/migration-pulse.css
  - assets/tableau.extensions.1.latest.js
  - assets/us-counties-topojson.json or county-centroids.json
  - README.md
- Runtime:
  - Initialize with tableau.extensions.initializeAsync().
  - Use a settings dialog to select the Extension Feed worksheet.
  - Read worksheet data with Worksheet.getSummaryDataReaderAsync().
  - Render with D3 + Canvas for performance across 3,139 counties.
  - Use TopoJSON/centroids keyed by County FIPS because the local CSV has FIPS but no latitude/longitude.
  - Re-render on filter/data changes.
  - Persist settings for feed worksheet, mode, color theme, and Top N.

Animation modes
- Pulse: all counties emit one pulse; radius and opacity scale by absolute net migrants.
- Build-up: counties appear in rank order from largest gain to largest loss, labeled as "ranked decade totals," not annual time.
- Scanner: a moving time bar sweeps west-to-east or largest-to-smallest to reveal counties.
- Focus mode: selected state expands; national map fades to context.

Visualization ideas
- Animated county pulse map: best hero view; shows where net gains/losses concentrate.
- Rate vs volume quadrant chart: separates huge counties with modest rates from small counties with extreme rates.
- Top movers leaderboard: ranked gain/loss bars with state and population context.
- State small multiples: one compact map or bar per state to show regional patterns.
- County detail strip: selected county card with population, net migrants, rate, and sex split.
- Outlier finder: highlight counties with high rate but low total volume, and high volume but low rate.
- Native map + extension combo: use Tableau's native filled map for accurate geography, extension as animated focus panel.

Design stance
- Keep dashboard analytical, not gimmicky.
- Animation should reveal magnitude and direction, not imply exact movement paths.
- Lead with one question: "Which counties were migration magnets, and which saw the biggest net outflow?"
- Use source caveat directly in the viz: "Net migration = in-migrants minus out-migrants, 2010-2020 estimate. Not origin-destination flows."
