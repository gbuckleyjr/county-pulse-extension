# Exchange Assets

This folder contains draft Tableau Exchange listing assets for County Pulse.

## Files

- `listing-copy.md`: product name, tagline, long description, categories, audience, limitations, and links.
- `how-it-works.md`: field mapping and author setup notes.
- `county-pulse-icon-280.png`: 280x280 transparent PNG icon.
- `screenshot-overview.png`: 1200x680 overview screenshot draft.
- `screenshot-rank-build.png`: 1200x680 rank-build screenshot draft.
- `screenshot-tooltip.png`: 1200x680 tooltip/detail screenshot draft.

## Screenshot Status
