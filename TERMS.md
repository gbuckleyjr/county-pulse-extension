County Pulse is provided as a client-side Tableau viz extension for U.S. county-level analysis.

## Acceptable Use

Do not use County Pulse to:

- publish confidential, regulated, or personal data unless you have completed your own review and have permission to do so

## Tableau Requirements

County Pulse must be loaded through Tableau's extension mechanisms. Tableau Cloud and Tableau Server administrators may need to allow extensions and safelist the hosted URL before users can run it.

Tableau Public compatibility depends on Tableau's extension support and approval process. A workbook may fail to publish or render on Tableau Public if the extension is not approved for that environment.
